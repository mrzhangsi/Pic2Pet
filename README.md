# Pic2Pet

一张图片，直接变成桌面宠物。跨平台（Windows / macOS / Linux），基于 Qt 6 + C++20 重写自 Petra 的 2.5D 桌宠思路，目标是在内存占用、启动速度和帧时间抖动上优于 WebView 方案，并原生支持 GIF / APNG。

> 当前状态：**M1 可发布 + 动作系统已起步 + AI 教官 + 网站白名单** —— 支持 GIF / APNG / 静态图播放，含托盘、设置、开机自启、滚轮缩放、暂停/继续、应用图标，以及「待机 / 单击 / 双击 / 拖拽 / 输入」动作系统（可在「动作设置」窗口里逐个指定素材）。新增 **AI 教官**：定时看你有没有在学习，分心了提醒你；以及配套的 **网站白名单（Edge）**：开启后本机 Edge 只能访问白名单网站，退出 Pic2Pet 自动解除。M2（2.5D / PSD）及之后仍在规划。

## 🚧 设计红线

**素材门槛守在「一张图 + AI 能完成的处理」之内。**

这个软件的出发点是**尽量规避复杂的人为操作**。抠图、去背景、生成一段简单动作这类**粗活**可以交给 AI；
但"把角色切成身体/左右手并对齐锚点"这类**精细拆分**，现阶段 AI 做不稳、最后一定落到人手上一点点对 ——
所以：**凡是要求用户手工精修素材的功能，一律不做**（哪怕技术上做得到）。

我们已经因此砍掉过两个功能（目录命名约定、分层精灵），也因此把原计划的 **M2（PSD/2.5D）**
从"规划中"退回"待重新评估"。详见 `技术方案.md` 第 15 节。

## ✨ 特性

- **一张图直出桌宠**：把任意图片或动图拖到角色上即可，无需任何配置
- **丰富格式**：`.gif`（动图）· `.png`（含 APNG 动图）· `.jpg` `.bmp`（静态）
  - 说明：**不支持 WebP** —— Qt 官方预编译包不带 WebP 图像插件，需要自带 libwebp 才能支持，列为后续里程碑
- **动作系统**：待机 / 单击 / 双击 / 拖拽 / **输入（敲键盘）** 各自可配**素材 + 音频**（两者完全独立，可以只配其一）；
  素材若是静态图片，还能单独设「停留时长」。全部在「动作设置」窗口里配置，改动即时生效
- **输入模式（可选，默认关）**：开启后全局监听键盘，你敲键时桌宠播放「输入」动作（带节流，打字不会狂闪）。
  只取虚拟键码、**不记录按键内容**；因为是挂钩式能力，会加重杀软误报 —— 详见下方「被报毒」一节
- **动态效果**：**呼吸 + 打字回弹 + 拖拽倾斜**三个通道各算各的、最后叠加 —— 呼吸不会因打字中断，
  打字也不会重置呼吸；按键给弹簧一个冲量，宠物会"一弹一弹"；拖住甩时身子朝**运动反方向**倒（惯性）。
  这是"不用 Live2D 也有手感"的做法，靠的是**参数化通道**而不是模型格式。
  强度在右键菜单里调（关 / 弱 / 中 / 强），默认「中」
- **按键提示**：输入模式下敲键时，在桌宠上方冒一个圆角小气泡显示刚按下的键
  （字母 / 数字 / 空格 / 回车 / 退格 / 方向键 / F1–F12 …）。它只是**屏幕上短暂显示**，
  不记录、不落盘、不打日志；可在菜单里单独关掉
- **AI 教官（可选，默认关）**：定期看看你在做什么，分心了提醒你 —— 三级判定：
  ① 本地规则（锁屏 / 键鼠空闲 / 画面帧差 / 摄像头肤色在场检测，零开销）；
  ② 本地拿不准时才把「屏幕 + 摄像头」合成一张图调**视觉大模型**（默认 DeepSeek，任何 OpenAI 兼容端点都行）；
  ③ 状态机（EWMA + 自适应采样间隔 + 告警冷却）决定要不要打扰你。
  **没配 API key 也能跑**（只走本地规则）；不配摄像头也能跑（只凭屏幕判定）。
  采样间隔随「持续在学」自动拉长到 5 分钟，学一天约 ¥0.04~0.09；
  还有可选的**课堂模式（番茄钟）**：专注一段时间后提醒休息，休息期间完全不抓拍
- **网站白名单（Edge，可选，默认关）**：开启后本机 **Microsoft Edge 只能访问白名单里的网站**
  （路径按**前缀匹配**：`example.com/math` 放行所有 `/math…` 开头的路径；
  主机名不带点 = 含全部子域，带点 = 只匹配该主机；不带 `https://` 时 http/https 都放行）。
  用的是 **Edge 官方策略**（URLBlocklist 全拦 + URLAllowlist 放行白名单），Edge 原生拦页。
  **只影响 Edge**，其他浏览器不受限制。
  - **每次开启 / 关闭都会弹一次管理员授权（UAC）**。原因是策略必须写在
    `HKLM\SOFTWARE\Policies\Microsoft\Edge`：**用户级那条路 `HKCU\SOFTWARE\Policies`
    出厂就只读**（只有 SYSTEM / Administrators 可写，微软文档说明这是为了防止用户
    自行解除组策略），而 Edge 在 Windows 上只有注册表一个策略入口。
  - 因此这是**机器级**限制：**本机所有 Windows 账户**的 Edge 都会被一起限。
  - **退出 Pic2Pet 时自动解除**（同样弹一次 UAC；用户预先配的策略值会先备份、
    退出时原样恢复）。若 Pic2Pet 被强行杀死，策略会留着继续生效，下次启动会提示。
  - ⚠️ **策略不是实时生效的**：Edge 在启动时读，之后约每 15 分钟重读一次，
    或在 `edge://policy` 点「重新加载」。设置页里有「打开 edge://policy」按钮。
  - 条目在设置页「AI 教官」分页里配置，**空名单禁止开启**（否则等于把 Edge 整个关死）。
- **低开销**：素材加载时一次性预解码，播放期零解码；播放按"下一帧 deadline"唤醒（不是固定 16ms 空转）；
  窗口不可见或最小化时全部停摆
  - 实测（240×240）：动画内存 ≈ 90 MB、唤醒 ≈ 12 次/秒@10fps；静态图内存 ≈ 80 MB
  - **CPU 取决于「动态效果」**：设「关/弱」时静态图 **CPU ≈ 0（完全不重绘）**、动画 ≈ 1.2%；
    设「中/强」时因为要呼吸，会持续重绘（静态图 ≈ 2%、动画 ≈ 2–4%）。想省电就调「弱」——
    打字回弹/倾斜仍在，只是静止时不重绘
- **交互**：鼠标穿透、始终置顶、系统托盘、右键菜单（设置 / 打开素材 / 最近素材 / 缩放 / 透明度 / 暂停 / 动作 / 动作设置 / 输入 / 动态效果 / AI 教官 / 网站白名单 / 开机自启 / 显示隐藏 / 退出）
- **设置界面**：左侧边栏 + 分页（素材 / 动作 / 输入 / 动态效果 / 外观 / 通用 / AI 教官），浅色简洁风。
  开关、分段控件、侧栏图标都是自绘的矢量件，不引入任何第三方 UI 库
- **原生渲染**：桌面 OpenGL，不依赖浏览器内核

## 📦 下载

前往 **[Releases](../../releases)** 页面，下载 `Pic2Pet-<版本>.zip`，解压后双击 `Pic2Pet.exe` 即可运行。

> 需要目标机器已安装 **Visual C++ 2015–2022 Redistributable**（Windows）。

## 🚀 快速开始

1. 从 Releases 下载并解压
2. 双击 `Pic2Pet.exe`（会自动恢复上次使用的素材与窗口位置）
3. **把任意图片 / 动图拖到角色身上**即可更换素材
4. 右键角色或托盘图标，打开菜单：
   - 打开素材 / 最近素材
   - 缩放（也可用**鼠标滚轮**实时缩放）
   - 透明度
   - 暂停 / 继续动画
   - **动作**（手动触发待机 / 单击 / 双击 / 拖拽 / 输入）
   - **动作设置…**（给每个动作单独指定素材、音频与静态图停留时长）
   - **动态效果**（关 / 弱 / 中 / 强：呼吸、打字回弹）
   - **AI 教官（学习）**：一键用默认配置启动AI教官（目标：学习）
   - **AI 教官设置…**：打开设置页的「AI 教官」分页做详细配置
   - **网站白名单（Edge）**：开启后 Edge 只能访问白名单网站（条目在「AI 教官设置…」页里配）；退出 Pic2Pet 自动解除
   - **输入模式（跟随键盘）**（默认关，全局键盘监听的唯一开关）
   - **按键提示（气泡）**（输入模式下敲键时显示按下的键）
   - 开机自启 / 始终置顶 / 显示隐藏
   - 退出

命令行用法：

```bat
Pic2Pet.exe                         REM 启动（恢复上次素材与位置）
Pic2Pet.exe test.gif               REM 直接加载指定素材文件
Pic2Pet.exe --media <路径>         REM 同上，参数形式
Pic2Pet.exe --no-tray              REM 不显示托盘
Pic2Pet.exe --teacher              REM 启动后立即开启 AI 教官监控（当前配置，默认目标：学习）
```

## 🛡️ 关于「被报毒 / SmartScreen」

本程序**不含任何恶意行为**：鼠标穿透只作用于自身窗口、开机自启只在你主动勾选时写入当前用户的启动项，无注入、无提权。

**三处例外请知悉**：

1. **「输入模式」（默认关闭）**：勾选后会调用 `SetWindowsHookEx(WH_KEYBOARD_LL)` 安装一个**全局低层键盘钩子**，用于"你敲键盘时桌宠跟着动"。它只把按键的**虚拟键码**交给桌宠逻辑，**不记录、不落盘、不打日志**任何按键内容，但**客观上它是一个钩子**。
2. **「AI 教官」（默认关闭）**：启动后会**定时截屏 / 拍照**，并在本地规则拿不准时把「屏幕 + 摄像头」合成的一张图通过 HTTPS 发给你配置的大模型端点（默认 DeepSeek）做判定。图片**不落盘**、不上传除该端点外的任何地方，日志只记字节数；API key 只写本机配置文件。停止后本功能完全静默。
3. **「网站白名单（Edge）」（默认关闭）**：开启后会**弹一次 UAC 管理员授权**，然后以提权子进程往 `HKLM\SOFTWARE\Policies\Microsoft\Edge` 写两个键值（URLBlocklist 全拦 + URLAllowlist 放行白名单）来限制 Edge 上网。你预先配的 Edge 策略值会先备份到 `HKLM\SOFTWARE\Pic2Pet\WebFilterBackup`，**退出 Pic2Pet 时（再弹一次 UAC）原样恢复并清除我们写的值**。Edge 里显示「Managed by your organization」是预期行为。这必然比普通权限程序更容易触发杀软提示——它确实在**修改系统级安全策略**，这是功能的性质决定的，不是可以绕过的误报。

另外一处需要更正：exe 清单仍是 `asInvoker`（主进程不申请管理员），但**开启 / 关闭白名单时会用 `runas` 拉起一个提权的自身子进程**去写策略——这是 Edge 策略唯一可行的官方途径（用户级策略键出厂只读）。

但作为**未签名 exe + 鼠标穿透 + 可选开机自启 +（可选）全局键盘钩子 +（可选）联网 +（可选）写 Edge 策略**的组合，容易被 Windows Defender / SmartScreen 误报（**开启输入模式会明显加重误报**）。我们已采取缓解措施：exe 内嵌应用清单声明不申请管理员权限（`asInvoker`）、DPI 感知、Win10/11 兼容；键盘监听、AI 教官与网站白名单**默认关闭**，只有你主动开启。若仍被拦截，最彻底的办法是对 exe 做 **Authenticode 代码签名**（需代码签名证书）。开源 + CI 可复现构建也便于你自行核验二进制与源码一致。
