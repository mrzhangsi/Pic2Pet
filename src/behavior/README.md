# behavior/ — 行为状态机（M3）

移植 `参考项目/Petra/src/autonomous/BehaviorEngine.ts`（602 行）。

状态：
- `Roam` — 工作区内随机取点，按档位速度移动，到达后按 restChance 休息
- `Flee` — 光标进入 165px 半径 → 背离光标逃跑 260px，持续 900~1500ms
- `Chase` — 逗猫棒模式，追光标（目标点夹在"模型完整可见"范围内）
- `Idle` — 沉到就近屏幕边缘（上半屏 → 顶部倒挂 180°），完全静止
- `DragSuspend` — 拖拽中暂停自主行为
- `LowActivity` — 低档：原地静止，仅保留呼吸/眨眼/视线

活动三档（restBase / restChance / radiusDiv / speed）：
低 `600000 / 0.95 / 8 / 12`　中 `8000 / 0.3 / 3.5 / 55`　高 `1500 / 0.05 / 2 / 120`

必带细节：**模型偏移补偿** —— 窗口可以探出屏幕，但角色不能，每帧用角色包围盒
反算窗口内偏移（平滑系数 0.3）。这是 Petra 手感的关键，别漏。
