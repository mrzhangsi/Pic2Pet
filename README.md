# Pic2Pet

一张图片，直接变成桌面宠物。跨平台（Windows / macOS / Linux），基于 Qt 6 + C++20 重写自 Petra 的 2.5D 桌宠思路，目标是在内存占用、启动速度和帧时间抖动上优于 WebView 方案，并原生支持 GIF / APNG。

> 当前状态：**M1 可发布 + 动作系统已起步** —— 支持 GIF / APNG / 静态图播放，含托盘、设置、开机自启、滚轮缩放、暂停/继续、应用图标，以及「待机 / 单击 / 双击 / 拖拽」动作系统（可在「动作设置」窗口里逐个指定素材）。M2（2.5D / PSD）及之后仍在规划。

## ✨ 特性

- **一张图直出桌宠**：把任意图片或动图拖到角色上即可，无需任何配置
- **丰富格式**：`.gif`（动图）· `.png`（含 APNG 动图）· `.jpg` `.bmp`（静态）
  - 说明：**不支持 WebP** —— Qt 官方预编译包不带 WebP 图像插件，需要自带 libwebp 才能支持，列为后续里程碑
- **动作系统**：待机 / 单击 / 双击 / 拖拽 / **输入（敲键盘）** 各自可配**素材 + 音频**（两者完全独立，可以只配其一）；
  素材若是静态图片，还能单独设「停留时长」。全部在「动作设置」窗口里配置，改动即时生效
- **输入模式（可选，默认关）**：开启后全局监听键盘，你敲键时桌宠播放「输入」动作（带节流，打字不会狂闪）。
  只取虚拟键码、**不记录按键内容**；因为是挂钩式能力，会加重杀软误报 —— 详见下方「被报毒」一节
- **动态效果**：**呼吸 + 打字回弹 + 拖拽倾斜**三个通道各算各的、最后叠加 —— 呼吸不会因打字中断，
  打字也不会重置呼吸；按键给弹簧一个冲量，宠物会"一弹一弹"；拖住甩时身子朝**运动反方向**倒（惯性）。
  这是"不用 Live2D 也有手感"的做法，靠的是**参数化通道**而不是模型格式。
  强度在右键菜单里调（关 / 弱 / 中 / 强），默认「中」
- **按键提示**：输入模式下敲键时，在桌宠上方冒一个圆角小气泡显示刚按下的键
  （字母 / 数字 / 空格 / 回车 / 退格 / 方向键 / F1–F12 …）。它只是**屏幕上短暂显示**，
  不记录、不落盘、不打日志；可在菜单里单独关掉
- **低开销**：素材加载时一次性预解码，播放期零解码；播放按"下一帧 deadline"唤醒（不是固定 16ms 空转）；
  窗口不可见或最小化时全部停摆
  - 实测（240×240）：动画内存 ≈ 90 MB、唤醒 ≈ 12 次/秒@10fps；静态图内存 ≈ 80 MB
  - **CPU 取决于「动态效果」**：设「关/弱」时静态图 **CPU ≈ 0（完全不重绘）**、动画 ≈ 1.2%；
    设「中/强」时因为要呼吸，会持续重绘（静态图 ≈ 2%、动画 ≈ 2–4%）。想省电就调「弱」——
    打字回弹/倾斜仍在，只是静止时不重绘
- **交互**：鼠标穿透、始终置顶、系统托盘、右键菜单（打开素材 / 最近素材 / 缩放 / 透明度 / 暂停 / 动作 / 动作设置 / 开机自启 / 显示隐藏 / 退出）
- **原生渲染**：桌面 OpenGL，不依赖浏览器内核

## 📦 下载

前往 **[Releases](../../releases)** 页面，下载 `Pic2Pet-<版本>.zip`，解压后双击 `Pic2Pet.exe` 即可运行。

> 需要目标机器已安装 **Visual C++ 2015–2022 Redistributable**（Windows）。

## 🚀 快速开始

1. 从 Releases 下载并解压
2. 双击 `Pic2Pet.exe`（会自动恢复上次使用的素材与窗口位置）
3. **把任意图片 / 动图拖到角色身上**即可更换素材
4. 右键角色或托盘图标，打开菜单：
   - 打开素材 / 最近素材
   - 缩放（也可用**鼠标滚轮**实时缩放）
   - 透明度
   - 暂停 / 继续动画
   - **动作**（手动触发待机 / 单击 / 双击 / 拖拽 / 输入）
   - **动作设置…**（给每个动作单独指定素材、音频与静态图停留时长）
   - **动态效果**（关 / 弱 / 中 / 强：呼吸、打字回弹）
   - **输入模式（跟随键盘）**（默认关，全局键盘监听的唯一开关）
   - **按键提示（气泡）**（输入模式下敲键时显示按下的键）
   - 开机自启 / 始终置顶 / 显示隐藏
   - 退出

命令行用法：

```bat
Pic2Pet.exe                         REM 启动（恢复上次素材与位置）
Pic2Pet.exe test.gif               REM 直接加载指定素材文件
Pic2Pet.exe --media <路径>         REM 同上，参数形式
Pic2Pet.exe --no-tray              REM 不显示托盘
```

## 🛡️ 关于「被报毒 / SmartScreen」

本程序**不含任何恶意行为**：鼠标穿透只作用于自身窗口、开机自启只在你主动勾选时写入当前用户的启动项，无注入、无提权、无网络访问。

**唯一的例外是「输入模式」（默认关闭）**：勾选后会调用 `SetWindowsHookEx(WH_KEYBOARD_LL)` 安装一个**全局低层键盘钩子**，用于"你敲键盘时桌宠跟着动"。它只把按键的**虚拟键码**交给桌宠逻辑，**不记录、不落盘、不打日志**任何按键内容，但**客观上它是一个钩子**，请知悉。

但作为**未签名 exe + 鼠标穿透 + 可选开机自启 +（可选）全局键盘钩子**的组合，容易被 Windows Defender / SmartScreen 误报（**开启输入模式会明显加重误报**）。我们已采取缓解措施：exe 内嵌应用清单声明不申请管理员权限（`asInvoker`）、DPI 感知、Win10/11 兼容；键盘监听**默认关闭**，只有你主动勾选才装钩子。若仍被拦截，最彻底的办法是对 exe 做 **Authenticode 代码签名**（需代码签名证书）。开源 + CI 可复现构建也便于你自行核验二进制与源码一致。
