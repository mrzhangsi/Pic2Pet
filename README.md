# Pic2Pet

一张图片，直接变成桌面宠物。跨平台（Windows / macOS / Linux），基于 Qt 6 + C++20 重写自 Petra 的 2.5D 桌宠思路，目标是在内存占用、启动速度和帧时间抖动上优于 WebView 方案，并原生支持 GIF / APNG。

> 当前状态：**M1 可发布** —— 已支持 GIF / APNG / 目录序列 / 静态图播放，含托盘、设置、开机自启、滚轮缩放。M2（2.5D / PSD）及之后仍在规划。

## ✨ 特性

- **一张图直出桌宠**：把任意图片或动图拖到角色上即可，无需任何配置
- **丰富格式**：`.gif`（动图）· `.png`（含 APNG 动图）· `.jpg` `.bmp` `.webp`（静态）· **目录**（图片按文件名排序组成序列）
- **低开销**：素材加载时一次性预解码，播放期零解码；窗口不可见或静态图时自动停渲染
  - 实测：动画内存 ≈ 85 MB、待机 CPU ≈ 0–1.6%；静态图内存 ≈ 70 MB、CPU ≈ 0
- **交互**：鼠标穿透、始终置顶、系统托盘、右键菜单（缩放 / 透明度 / 开机自启 / 显示隐藏 / 退出）
- **原生渲染**：桌面 OpenGL，不依赖浏览器内核

## 📦 下载

前往 **[Releases](../../releases)** 页面，下载 `Pic2Pet-<版本>.zip`，解压后双击 `Pic2Pet.exe` 即可运行。

> 需要目标机器已安装 **Visual C++ 2015–2022 Redistributable**（Windows）。

## 🚀 快速开始

1. 从 Releases 下载并解压
2. 双击 `Pic2Pet.exe`（会自动恢复上次使用的素材与窗口位置）
3. **把任意图片 / 动图拖到角色身上**即可更换素材
4. 右键角色或托盘图标，打开菜单：
   - 打开素材 / 最近素材
   - 缩放（也可用**鼠标滚轮**实时缩放）
   - 透明度
   - 开机自启 / 始终置顶 / 显示隐藏
   - 退出

命令行用法：

```bat
Pic2Pet.exe                         REM 启动（恢复上次素材与位置）
Pic2Pet.exe test.gif               REM 直接加载指定素材
Pic2Pet.exe --media <路径>         REM 同上，参数形式
Pic2Pet.exe --no-tray              REM 不显示托盘
```

## 🛡️ 关于「被报毒 / SmartScreen」

本程序**不含任何恶意行为**：鼠标穿透只作用于自身窗口、开机自启只在你主动勾选时写入当前用户的启动项，无注入、无挂钩、无提权、无网络访问。

但作为**未签名 exe + 鼠标穿透 + 可选开机自启**的组合，容易被 Windows Defender / SmartScreen 误报。我们已采取缓解措施：exe 内嵌应用清单声明不申请管理员权限（`asInvoker`）、DPI 感知、Win10/11 兼容。若仍被拦截，最彻底的办法是对 exe 做 **Authenticode 代码签名**（需代码签名证书）。开源 + CI 可复现构建也便于你自行核验二进制与源码一致。
